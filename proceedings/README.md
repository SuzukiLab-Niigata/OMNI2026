# Proceedings PDF

Place the book in this folder with exactly this file name:

```
proceedings/OMNI2026_Proceedings.pdf
```

The proceedings page (`https://suzukilab-niigata.github.io/OMNI2026/proceedings/`) loads this file and shows it.
To update the book, overwrite the file with the same name, then commit and push. The link and the QR code never change.

QR code images: `assets/qr/proceedings-qr.png` (print) and `assets/qr/proceedings-qr.svg` (vector).

Notes
- Before exporting from Word, accept all tracked changes and hide comments (Review → Accept All Changes / No Markup).
- GitHub rejects files over 100 MB and warns above 50 MB. Use "Reduce file size" / "Optimize for online" when exporting if the PDF is large.
